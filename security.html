Security questions, answered

Do you claim end-to-end encryption?

No. MEMRYA does not claim end-to-end encryption. Private account storage, access controls and server-side secret handling are different safeguards.

Do you claim SOC 2, HIPAA or GDPR certification?

No certification or independent attestation is claimed here. Specific legal or enterprise compliance requirements must be reviewed and verified separately.

Can organizations keep every recording inside their own infrastructure?

Private-cloud or on-premises deployment is an exploration, not a currently offered feature. Ask us about requirements before making an enterprise decision.

Where do I report a security concern?

Email dev@memrya.co with a description of the issue. Avoid sending live account credentials or sensitive recordings in the report.

MEMRYA is designed to keep your account data private, service credentials on our servers and each account's data separate. The sections below describe how the service is structured.

Server-side secrets

Provider and API secrets used to talk to processing providers are kept server-side and are not included in the mobile client.

Private, owner-scoped storage

Cloud storage is private, and access to your data is scoped to the account that owns it.

Separate accounts

Each account's data is kept separate from every other account. We treat this as a core product requirement.

Encryption

We do not claim end-to-end encryption. Security is built on server-side secret handling and private, owner-scoped storage as described above, not on an end-to-end encryption guarantee.

Processing providers

Audio and transcript processing uses the providers listed on our Privacy page after you consent during setup. To request deletion, use available account controls or contact support.

Website security

This website itself enforces a strict Content-Security-Policy, uses no analytics, cookies, trackers or third-party JavaScript, and exposes no public API keys.

Reporting a concern

If you believe you have found a security issue, contact dev@memrya.co.
