Core app flow

Existing audio import

Import conversation audio from your device for transcription and analysis.

How it works

  1. Choose “Import conversation” in MEMRYA.
  2. Select an audio file you have permission to process.
  3. Start processing when you're ready; cloud processing uses minutes.
  4. Review transcript, summary, speakers, actions and source evidence.

Imported audio joins your connected memory with source evidence. Check the app for supported formats and processing options.

Planned. Not available yet.

Zoom

Zoom cloud recording import is in development for people who already record their meetings.

Intended workflow

  1. Authorize access to selected recordings when integration ships.
  2. Choose which conversations enter MEMRYA.
  3. Process approved recordings into your memory.
  4. Review sources and revoke access in settings.

No Zoom account connection is available from this page. We will not ask for Zoom credentials before the integration exists.

Planned. Not available yet.

Google Meet

Structured Google Meet transcript import is planned. No Google account connection is available yet.

Intended workflow

  1. Choose meetings or recordings for import.
  2. Review an available meeting transcript before deciding whether to analyze it.
  3. Review the resulting memory and source evidence.
  4. Control future access and disconnect when needed.

No Google sign-in or Meet permission request is active here.

In app testing

Google Calendar and reminders

Connected memory should make action easier, without surprising account permissions.

Designed for your review

  • A dated action can open a prefilled Google Calendar event draft for you to review.
  • MEMRYA never creates the event. You review and save it in Google Calendar.
  • Local reminder notifications can alert you to dated commitments with your permission.
  • Opening a calendar draft does not require access to all your calendar events.

These features are under testing and are not offered as public integrations yet.
